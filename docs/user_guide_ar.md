# دليل استخدام تطبيق Yarmouk Water Pro

تطبيق إدارة مياه اليرموك للهواتف (Android)، مخصص لمتابعة الموظفين والورشات والطلبات
داخل المؤسسة. هذا الدليل يشرح التثبيت، الإعداد، وتفاصيل كل شاشة.

---

## ١) متطلبات التشغيل

- هاتف Android 7.0 أو أحدث.
- تواجد الهاتف والخادم (الحاسوب الذي يعمل عليه الباك-إند) على **نفس شبكة الواي‑فاي**.
- عنوان الباك-إند يُكتب بهيئة `http://IP:8001` (مثال: `http://192.168.1.175:8001`
  أو `http://192.168.1.18:8001`).

## ٢) تثبيت التطبيق (APK)

1. انسخ ملف `app-release.apk` إلى الهاتف (عبر وصلة USB، أو تطبيق مشاركة، أو رفع سحابي).
2. افتح الملف على الهاتف وثبّته.
3. عند ظهور تحذير "مصدر غير معروف"، فعّل السماح بالتثبيت من المتصفح/مدير الملفات المعني،
   ثم أكمل التثبيت.
4. افتح التطبيق.

> ملاحظة: التطبيق موقّع بـ keystore خاص بالمشروع، لذا يمكن تحديثه لاحقاً دون إزالة النسخة القديمة.

## ٣) إعداد عنوان الخادم (IP الراوتر)

لأنك تتنقّل بين شبكات/عناوين (مثل `192.168.1.175` و `192.168.1.18`)، التطبيق يتيح
تغيير عنوان الخادم من داخله دون الحاجة لإعادة بناء الـ APK:

1. في شاشة الدخول، اضغط أيقونة **الإعدادات** (الترس) بالأعلى.
2. في الحقل "عنوان الخادم" اكتب العنوان كاملاً، مثال:
   `http://192.168.1.175:8001`
3. اضغط **حفظ**. يُحفظ العنوان على الجهاز ويُستخدم تلقائياً في الفتح القادم.
4. للعودة للافتراضي اضغط "استعادة الافتراضي".

يتصل التطبيق بالباك-إند على هذا العنوان لجلب البيانات والإشعارات الفورية (WebSocket).

## ٤) تسجيل الدخول

- **رقم الموظف** (مثل `EMP001`) + **كلمة المرور**.
- بيانات تجريبية: `EMP001` / `Yarmouk@2025` (مدير عام).
- عند النجاح تُفتح لوحة التحكم، ويُحفظ الجلسة محلياً.
- عند الفشل يظهر تنبيه "فشل تسجيل الدخول" — تحقق من رقم الموظف/كلمة المرور
  وأن عنوان الخادم صحيح وأن الباك-إند يعمل.

## ٥) لوحة التحكم (Dashboard)

تعرض بطاقة تعريفية (الاسم، المسمى الوظيفي، الوحدة التنظيمية) وأزرار سريعة:

| الزر | الوظيفة |
|------|---------|
| تسجيل دخول (Check In) | بدء الدوام — يفتح شاشة الحضور |
| تسجيل خروج (Check Out) | إنهاء الدوام — يفتح شاشة الحضور |
| إجازة | تقديم/متابعة طلب إجازة |
| عمل إضافي | تقديم/متابعة طلب عمل إضافي |
| صيانة | بلاغات/مهام الصيانة |
| GPS | تحديد الموقع والمسارات |
| تقارير | تقارير واستعلامات |
| إشعارات | قائمة الإشعارات (مع شارة بعدد غير المقروء) |
| الملف الشخصي | بيانات الموظف وتسجيل الخروج |

زر الجرس أعلى الشاشة يفتح الإشعارات، وشارة حمراء تظهر عدد الإشعارات الجديدة
تلقائياً عبر الاتصال الفوري.

## ٦) الحضور والانصراف (Attendance)

- يسجّل الحضور مع **الوقت والموقع GPS** تلقائياً (بإذن الموقع من الهاتف).
- "تسجيل دخول" يبدأ وردية، "تسجيل خروج" ينهيها.
- تظهر حالة التسجيل الحالية وتاريخ آخر عمليات.

## ٧) طلبات الإجازة (Leave)

- نموذج: النوع، من تاريخ، إلى تاريخ، السبب.
- بعد الإرسال يبقى "قيد المراجعة" حتى يوافق عليه مدير الموارد البشرية/المشرف،
  وعند الموافقة أو الرفض يصلك **إشعار فوري** تلقائي.

## ٨) العمل الإضافي (Overtime)

- نموذج: التاريخ، عدد الساعات، الوصف.
- نفس دورة الموافقة مع إشعار تلقائي عند البتّ بالطلب.

## ٩) الصيانة (Maintenance)

- إنشاء بلاغ صيانة وتعيين فني (worker) عند الحاجة.
- عند تعيين الفني يصله إشعار فوري بالمهمة.

## ١٠) الـ GPS

- عرض/تسجيل الموقع الحالي وربطه بالوردية أو المهمة.

## ١١) التقارير (Reports)

- استعلامات مجمّعة (حضور، إجازات، عمل إضافي، صيانة) حسب الصلاحية.

## ١٢) الإشعارات (Notifications)

- قائمة فورية تُحدّث لحظياً عبر WebSocket.
- زر "تحديد الكل كمقروء" لمسح الشارة.
- الإشعارات تشمل: موافقة/رفض طلباتك، وتكليفات الصيانة/الخدمة المسندة إليك.

## ١٣) الملف الشخصي (Profile)

- عرض بيانات الموظف، وزر **تسجيل الخروج**.

## ١٤) صلاحيات الأدوار

| الدور | صلاحيات رئيسية |
|------|----------------|
| مدير عام (general_manager) | كامل الصلاحيات + مراجعة الطلبات + سجلّ التدقيق |
| مدير موارد بشرية (hr_manager) | اعتماد الإجازات والعمل الإضافي |
| مشرف ميداني (field_supervisor) | اعتماد مهام الفريق الميداني |
| مشرف مكتبي (office_supervisor) | اعتماد مهام الفريق المكتبي |
| موظف | تقديم طلباته فقط + استقبال إشعاراته |

## ١٥) استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| فشل تسجيل الدخول | تأكد من رقم الموظف/كلمة المرور، ومن صحة عنوان الخادم، وأن الباك-إند يعمل |
| لا تصل إشعارات | تأكد من الاتصال بالواي‑فاي نفسه، وأن الإنترنت متاح؛ الإشعارات تتطلب WebSocket مفتوح |
| بطء أو 503 | ضغط مؤقت على الخادم — أعد المحاولة بعد لحظات |
| خطأ اتصال بالشبكة | تحقق أن الهاتف والخادم على نفس الواي‑فاي وأن جدار الحماية لا يحجب المنفذ 8001 |

## ١٦) للمطوّر (ملخص تقني)

- الواجهة: Flutter. الباك-إند: FastAPI (Python) + SQLite (PostgreSQL لاحقاً).
- عنوان الخادم قابل للتهيئة من داخل التطبيق (مخزّن عبر `shared_preferences`).
- الإشعارات الفورية عبر `WebSocket` على المسار `/ws/notifications` باستخدام رمز JWT.
- التطبيق معرّب بالكامل (RTL) ويدعم الثيم المريح للعين.
